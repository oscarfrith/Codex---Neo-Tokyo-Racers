## Tuning and easy reversion

In Studio Edit, select `ReplicatedStorage.Config.World.Lighting`, change **CycleMode** to **Stepped**, then restart Play. This restores the original stepped schedule, preset/sky behavior and original StageVisuals rules. Set it back to **Continuous** and restart to return to the new cycle. Mode is intentionally selected at startup. The default installer APPLY selects Stepped; CONTINUOUS explicitly enables the new mode.

Outdoor art tuning lives in `ReplicatedStorage.Modules.Game.World.LightingCycleDefinition`: edit the continuous overrides, not original LightingPresets. Keep ClockHours increasing through the unwrapped midnight values 24 and 28. BaseDurationSeconds remains 90. ContinuousGeographicLatitude, SunriseClockTime and SunsetClockTime should be tuned together against the actual sun path. Original garage/dealership presets are independent. ManualStage and AutoCycleEnabled still provide manual target selection; restarting auto rejoins the current phase immediately.

Full code recovery uses the same canonical installer in **Edit**, with operation **ROLLBACK**. It restores the seven captured source bodies, removes the five added attributes and deletes only the three verified unedited modules. It refuses partial/drifted state or modules that acquired unrelated contents. Original Edit Lighting properties were never changed, so no persistent Lighting-property restore is needed. Keep the repository evidence; no in-game backup folders exist.

For assistant-operated recovery, serve `scripts/continuous_lighting` locally, load `install.lua` through the Studio MCP Edit command and call the returned function with `AUDIT`, `STEPPED`, `CONTINUOUS` or `ROLLBACK`. This uses the same invocation as installation; the file is inert until called. Stop the temporary server afterward. Before any source revision, use the installed bundle's guarded rollback; do not overwrite it with a rebuilt bundle and then attempt to roll back mismatched source. Rebuild with prepare.py/build.py after reviewing live drift, install, verify, and recapture. Do not rerun older migrations.
