# Pulse UI previews (Phase 0)

Static HTML drawings of the Pulse screens, used to agree the look before any Roblox code is written. Nothing here is installed in Studio.

## Folders

| Path | Holds | Owner |
|---|---|---|
| `shared/pulse.css` | The preview kit: colour roles, type roles, every component class. Class names are stable; the file only grows | regular agent |
| `shared/icons.css` | Stand-in icons as CSS masks. Generated by `shared/make_icons.py` | regular agent |
| `shared/pulse.js`, `frames.js`, `sheet.js`, `boot.js` | Markup helpers so every frame uses the same component markup. `boot.js` is the one include a frame needs | regular agent |
| `shared/bg/` | Placeholder scenery, made from the accepted mockups by `shared/make_bg.py` (UI painted out, blurred). Not game art | regular agent |
| `regular/` | 1920x1080 frames `r00` to `r21` | regular agent |
| `compact/` | Phone frames | compact agent |
| `render.py` | Renders a folder of frames; the regular folder comes out as JPG | shared |

Output goes to `assets/ui/mockups/pulse_restyle/phase0/<folder>/`. For `regular`, `render.py` converts each PNG to JPG quality 90 and deletes the PNG, because the gallery links `.jpg` (`--png` keeps PNGs; `--jpg` does the same conversion for another folder). The regular gallery is `assets/ui/mockups/pulse_restyle/phase0/regular/index.html`.

## Re-render

Needs Chrome and Python 3, and a network connection the first time (Barlow loads from Google Fonts).

```text
py -3 render.py regular                      every frame at 1920x1080
py -3 render.py regular --only r01 r20       frames whose file name starts with r01 or r20
py -3 render.py regular --sizes 1280x720 1920x1080 2560x1440
py -3 render.py compact --sizes 844x390
py -3 shared/make_icons.py                   after editing the icon list
py -3 shared/make_bg.py                      to rebuild the placeholder scenery
```

A frame can pin its own sizes with `<meta name="render-sizes" content="1280x720 1920x1080 2560x1440">` (r21 does). With more than one size the file name gets a `_<W>x<H>` suffix. Set the `CHROME` environment variable if Chrome is not in its default place.

## Rules the frames follow

- **Roblox-achievable only.** Rectangles, hairlines, images, text. No blur, no rounded corners except the minimap, glyphs and rank ring, no letter-spacing (TextLabel has none). The only gradients are scrims, the main button and image stand-ins (gauge, slider strips, segmented bars).
- **Typeface.** Barlow italic 600, 800 and 900. Big numbers (`.num`) use Barlow Condensed ExtraBold Italic because the build draws them as image digits.
- **Type roles are cap heights** (plan section 4). CSS font-size is cap / 0.70; Roblox TextSize is cap / 0.583.
- **Scale** (plan 3.2). The stage is 1920x1080 design pixels. `pulse.js` applies `min(height / 1080, width / 1600)`, clamped 0.667 to 2.0 and snapped down to steps of 1/24, as CSS zoom.
- **Slots.** Title top-left, status cluster top-right, buttons in the order back, secondary, main. Review 2 (2026-10-09): on a screen with a rail the button row sits on the rail heading line, right-aligned to the margin (`P.btnrow(btns, "line")`); without a rail it is bottom-right (`P.btnrow(btns, "bar")`). Both use the one menu-row size: 64 high, text cap 20, main and buy cap 24. `"mid"` (under the stat panel, review 1) is no longer used by the regular frames.
- **Margins (review 1, 2026-10-09).** Menu sides 68 (`--margin`), menu bottom 30 (`--margin-bottom`), HUD 40 (`--hud-margin`), HUD bottom 28 (`--hud-bottom`). Before the review: 100, 44, 58, 40. Top-left items start below Roblox's top bar (next rule).
- **Roblox's own UI (review 2, 2026-10-09).** `shared/frames.js` wraps `P.page`: every screen frame gets a faint placeholder for the Roblox buttons (208 x 58 real pixels, two 44 px circles) and the stage gets the class `rbx` plus `--rbx-top`, `--rbx-w`, `--chat-b`, `--chat-r` in design pixels (real pixels divided by the scale). `.stage.rbx .title` starts at `--rbx-top` + 12. `P.freeroam` (or `P.page(html, {chat:1})`) also draws the chat window, 475 x 274 at (8, 70); it is left out with `sidePanel` or `dimmed`. Sheets pass `{noRbx:1}`. Top-left HUD content uses `top:calc(var(--chat-b) + 12px)`.
- **Tier colours (review 2, 2026-10-09).** `--tier-e` to `--tier-s` in `pulse.css`, taken from the game (`GarageUI.tierColours`). Badge: `P.tb(tier, rating, cls)` gives `<span class="tb tb-d"><b>D</b><i>321</i></span>`; sizes `sm`, `md`, `lg`; `on-light`, `dim`. `P.tile`, `P.status` and `P.statpanel` (`badge:["D",321]`) call `P.tierBadge`, which `pulse.js` defines with the old white markup and `frames.js` replaces with `P.tb`, so a folder that does not load `frames.js` is unchanged. Tier buttons: `.tierbtn.tb-c`, with `.on` and `.locked`.
- **Baked gradient images (review 3, 2026-10-09).** The minimap ring, rank arc, gauge layers and touch controls are real files from `../assets/out/` (and `../assets/touch_svg/` for the touch controls), not CSS drawings: `P.layer(file, size, cx, cy)` places one, `P.reveal(start, sweep)` is the stand-in for the rotating UIGradient mask, `P.gaugeArt(size, fraction, boost)` stacks the five gauge layers (403 px on desktop, 92 dp on phones). Run `py -3 ../assets/gen_rings.py` and `gen_touch_pulse.py` before rendering if the art changed. The selected base line, the title mark and the cash chip carry small CSS gradients (one UIGradient or image each in Roblox).
- **Free-roam HUD.** `P.freeroam` draws the minimap with the rank arc (`P.rankarc`); `sidePanel:1` hides both for the My Vehicles side panel (`.sidepanel`).

## Writing a frame

```html
<!doctype html><html><head><meta charset="utf-8"><title>rNN Name</title>
<script src="../shared/boot.js"></script></head><body><script>
P.page(`
  ${P.scene("garage")}<div class="scrim-garage"></div>
  ${P.title("CUSTOMISE")}${P.customiseTabs(0)}
  ${P.status({garage:"3 / 4"})}
  ${P.btnrow([P.btn("BACK","back"), P.btn("DRIVE","wheel","main")])}
`);
</script></body></html>
```

Do not name a page variable `top`, `name` or `status`; those are browser globals and the frame renders black.
