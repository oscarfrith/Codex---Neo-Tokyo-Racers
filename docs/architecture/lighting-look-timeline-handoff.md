## Behaviour and ownership

Uniform ClockTime makes one full day in ContinuousCycleDurationSeconds, seeded at 120. Day holds 08:00–16:00 and ClearNight 21:00–03:00. FourAM is dawn twilight at 04:30; SevenAM sunrise at 06:00; FivePM sunset at 18:00; EightPM dusk twilight at 19:30. Those four milestones hold their complete values for 0.4 game hours around the center. All numerical/colour properties use the same bounded smoothstep blend between holds. No TenAM/ThreePM outdoor stage, hidden glare cutoff or V1 brightness/exposure/haze overrides remain.

LightingServer validates and publishes complete configuration, phase metadata and discrete lamp/window signals. LightingCycle is pure calculation; LightingCycleDefinition is a config adapter. LightingClient remains the sole Continuous property writer. Existing context/startup/tag/streaming/UI/camera/vehicle/save owners remain. No new remotes, persistence fields, saved IDs, physical world edits or tag changes. Original LightingPresets, LightingSchedule, StageVisuals and skies are untouched.

Config.World.Lighting contains ContinuousLooks (eight milestones) and ContinuousPresets (six independent appearance copies with six sections each). Server attribute edits rebuild atomically; invalid runtime edits retain the last good configuration. CycleMode and sky-template property edits require restarting Play. ContinuousManualClockTime replaces ManualStage for Continuous. Edit-mode authoring persists with the place; Play-only experiments disappear on Stop.

ContinuousSky uses cloudless faces inspected from Creator Store asset **15296550452**, “Cloudless Sunless Day Sky” by **tungbearbear**. The installer creates only a Sky: side face 6444884337, down 6444884785, up 6412503613, retaining original DaySky sun/moon images, sizes 21/11 and 3,000 stars. The inserted inspection candidate was removed. No Terrain Clouds object existed. [Provenance](../../scripts/continuous_lighting/cloudless-sky.json). The blue background/reflections deliberately differ from old artwork.

Fresh before capture matched V1 exactly. Final capture inventories 168 sources and 138 selected nodes. Relative to V1: five revised sources, three root attributes and 53 added config/sky nodes. All 158 other original sources and all original captured objects/properties/tags remain exact. [Verification](../../scripts/continuous_lighting/evidence/v2/delivery-verification.json). This is not whole-world physical parity or a place-file backup.

Easy reversion: in Edit, set Config.World.Lighting.CycleMode to **Stepped** and restart Play. Return to **Continuous** the same way. This preserves custom tuning and restores the original 900-second schedule/effects/sky behaviour.

Full recovery uses the same [canonical install.lua](../../scripts/continuous_lighting/install.lua) in Edit with ROLLBACK. It restores seven original source bodies and removes only the exact verified three modules, eight attributes and three added trees. It refuses drifted sources, edited tuning, extra children or tags. Capture artist edits before preparing full recovery; do not force deletion. No in-game backups exist.

For assistant-operated delivery/recovery, serve scripts/continuous_lighting on a temporary localhost server and execute install.lua through Studio MCP Edit. The file returns a function accepting AUDIT, APPLY, STEPPED, CONTINUOUS or ROLLBACK. Fresh APPLY selects Stepped; CONTINUOUS explicitly activates it. Repeated APPLY on a verified installed Continuous setup is a no-op. Before source revisions, roll back using the installed bundle before rebuilding, preserving current authoring in a fresh capture. Never rerun historical migrations. Stop the temporary server afterward.
