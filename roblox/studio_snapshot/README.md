# Roblox Studio Snapshot

This folder is generated by:

```text
python scripts/import_studio_full_snapshot_export.py docs/studio-full-export-paste.txt
```

After a fresh Studio export/import, it should contain:

```text
hierarchy.json
hierarchy.md
source_manifest.json
checksums.json
```

Treat these files as a GitHub-readable mirror of Roblox Studio, not as live Rojo sync.
